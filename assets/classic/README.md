# Classic-theme asset provenance

The bundled artwork is not authored by this reconstruction. The official Debian source-package copyright record, copied verbatim for convenient attribution, is [DEBIAN-COPYRIGHT](DEBIAN-COPYRIGHT): it credits Alexander Babichev / Flowix, copyright 2003–2005, under GPL-2-or-later. See the repository's [GPL-2 license text](../../LICENSE), the English [asset license summary](../../ASSETS_LICENSES.md), and [third-party notices](../../THIRD_PARTY_NOTICES.md).

The 40 unmodified BMP files originate in Debian's `einstein_2.0.dfsg.2.orig.tar.gz` source archive (SHA-256 `93d6c275ae3be55a193b391965012fa56d62c95adcc4838844c45f64cda6b9c3`). In that archive, paths are under `einstein-2.0/res/`: cards `large-A1.bmp` through `large-F6.bmp` (only the `large-` prefix was removed from the filenames here), plus `rain.bmp`, `hint-near.bmp`, `hint-side.bmp`, and `betwarr.bmp`. The archive is available from [Debian's pool](https://deb.debian.org/debian/pool/main/e/einstein/einstein_2.0.dfsg.2.orig.tar.gz). [SHA256SUMS](SHA256SUMS) records the exact hashes and can be checked from the repository root with `sha256sum -c assets/classic/SHA256SUMS`.

The included F3 is the Debian bitmap (`ecb0a16ac577175e13947415b39a417e218e5b151f81d029417fbe41a49f2513`), not the differently hashed [Einstein Puzzle 2.2 F3](https://github.com/jordan-evens/einstein-puzzle/blob/b3054a83cb6220cc20ec80501e70b6206da7919d/res/icon-F3.bmp) (`e383615a6457869343ffffcf74da91fd523593af7a10f08cb34274ca78715199`); the latter is not redistributed. No historical game TTF, WAV, help text, package icon, or opaque `einstein.res` bundle is included. The default fonts/icons from egui have their own licenses; see the checked-in [current GUI dependency inventory](../../licenses/gui/inventory-wayland.json).

The BMP files are read as-is by the application and also provide the source bytes for embedded images. egui rendering supplies only scale, layout, and background treatment. This classic theme is not pixel-identical to the historical SDL window.
